# 3.1 基础监督学习

## 一.线性回归


### 1. 核心概念与模型定义
*   **应用场景**：用于预测连续数值（如预测房价）。
*   **符号定义**：
    *   \(x^{(i)}\)：第 \(i\) 个训练样本的特征集合（向量）。
    *   \(n\)：特征的数量（\(x_1, x_2, ..., x_n\)）。
    *   \(m\)：训练样本的总数。
    *   \(y^{(i)}\)：第 \(i\) 个样本的真实值。
*   **模型假设函数 (Hypothesis Function)**：
    *   单特征（特例）：\(f_{w,b}(x) = wx + b\)
    *   多特征（通用）：\(f_{\vec{w},b}(\vec{x}) = w_1x_1 + w_2x_2 + ... + w_nx_n + b\)
    *   **向量化表示**（Python 实现重点）：\(f_{\vec{w},b}(\vec{x}) = \vec{w} \cdot \vec{x} + b\) 
        *   *注：代码中使用 `np.dot(w, x) + b`，比写 for 循环快得多。*

### 2. 代价函数 
*   **定义**：用来衡量模型预测值与真实值之间误差的函数（即“纵向距离的平方的平均值”）。
*   **公式**：
    \[
J(\vec{w}, b) = \frac{1}{2m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})^2
\]
    *(注：\(1/2\) 是为了求导时与平方项的 \(2\) 抵消，方便计算)*
*   **目标**：\(\min_{w, b} J(\vec{w}, b)\) （寻找使代价函数最小的参数 \(w\) 和 \(b\)）

### 3. 梯度下降 
*   **核心思想**：通过迭代，沿着代价函数下降最快的方向（梯度反方向）更新参数，直到达到局部/全局最小值。
*   **更新公式**：
    *   \(w_j = w_j - \alpha \frac{\partial}{\partial w_j} J(\vec{w}, b)\)  （对所有特征 \(j=1...n\)）
    *   \(b = b - \alpha \frac{\partial}{\partial b} J(\vec{w}, b)\)
    *   *注意：必须“同步更新” (Simultaneously update) 所有的 \(w\) 和 \(b\)。*
*   **推导后的更新公式**：
    *   \(w_j = w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)}) x_j^{(i)}\)
    *   \(b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})\)    
*   **学习率 \(\alpha\) (Learning Rate)**：
    *   \(\alpha\) 太小：收敛速度很慢。
    *   \(\alpha\) 太大：可能会越过最小值，导致无法收敛甚至发散。
*   **梯度下降收敛性**：
    *   通过设置一个阈值 \(\epsilon\)（如 \(10^{-3}\)），当代价函数 \(J\) 在一次迭代中的下降幅度小于 \(\epsilon\) 时，可自动判定为基本收敛。
    *   也可以通过观察 \(J\) 的迭代曲线来判断。

### 4. 特征缩放 
*   **目的**：当多个特征的取值范围差异巨大时（如面积 \(300-2000\)，房间数 \(0-5\)），梯度下降会走“之”字形，收敛非常缓慢。缩放后能让梯度下降更快。
*   **三种方法**：
    1.  **直接除以最大值 (Max scaling)**：\(x_1 = \frac{x_1}{2000}\)，让范围大致在 \(0 \le x \le 1\) 之间。
    2.  **均值归一化 (Mean Normalization)**：\(x_1 = \frac{x_1 - \mu_1}{max - min}\)，让特征以 \(0\) 为中心。
    3.  **Z-score 标准化 (Z-score Normalization)**：\(x_1 = \frac{x_1 - \mu_1}{\sigma_1}\)，除以标准差。

### 5. 多项式回归 
*   **概念**：本质依然是线性回归，只是通过“特征工程”创造了新特征（如已知面积 \(x_1\) 和 宽 \(x_2\)，构造新特征面积 \(x_3 = x_1 \times x_2\)）。只要参数 \(w\) 是线性的，就可以用上面的梯度下降法求解。
*   **正规方程 (Normal Equation)**：对于特征数不多的情况，可以直接通过矩阵运算一次性求出最优解，无需迭代。但特征数很大时计算量过大，仍以梯度下降为主。

## 二.逻辑回归

> **核心直觉**：逻辑回归虽然名字里有“回归”，但它本质上是用于**二分类问题**（输出标签 \(y\) 为 \(0\) 或 \(1\)）。它通过 Sigmoid 函数，将线性回归的输出“扭曲”压缩到 \((0, 1)\) 之间，将其转化为**概率输出**。

### 1. 为啥用逻辑回归
*   **直观理解**：如果我们要将两类事物分开，肉眼能看到一个分布，理论上可以用线性回归画一条线（决策边界）硬切。设定阈值（如 \(0.5\)），大于 \(0.5\) 为 \(1\)，小于为 \(0\)。
*   **存在的问题**：一旦出现极端的离群点（outliers），拟合出的直线会发生巨大偏移，导致原本能正确分类的样本被错误分类。且线性回归输出值可能远小于 \(0\) 或远大于 \(1\)，不符合概率的定义。

### 2. 逻辑回归的假设函数 
*   **引入 Sigmoid 函数**（也称 Logistic 函数）：
    \[
g(z) = \frac{1}{1 + e^{-z}}
\]
    *   它将任意实数映射到 \((0, 1)\) 区间。
    *   当 \(z \to +\infty\) 时，\(g(z) \to 1\)；当 \(z \to -\infty\) 时，\(g(z) \to 0\)。
*   **组合成逻辑回归模型**：
    将线性模型 \(z = \vec{w} \cdot \vec{x} + b\) 代入 Sigmoid：
    \[
f_{\vec{w},b}(\vec{x}) = g(\vec{w} \cdot \vec{x} + b) = \frac{1}{1 + e^{-(\vec{w} \cdot \vec{x} + b)}}
\]
*   **概率解释**：\(f_{\vec{w},b}(\vec{x})\) 代表在给定特征 \(\vec{x}\) 和参数 \(\vec{w},b\) 的情况下，**\(y=1\) 的概率**（即 \(P(y=1|\vec{x};\vec{w},b)\)）。

### 3. 决策边界 
*   **预测规则**：
    *   若 \(f_{\vec{w},b}(\vec{x}) \ge 0.5\)，预测 \(\hat{y}=1\)（此时 \(z \ge 0\)）。
    *   若 \(f_{\vec{w},b}(\vec{x}) < 0.5\)，预测 \(\hat{y}=0\)（此时 \(z < 0\)）。
*   **边界的形成**：令 \(z = \vec{w} \cdot \vec{x} + b = 0\)，解出的曲线或平面即为决策边界。
    *   **线性边界**：若特征是一次的，如 \(w_1x_1 + w_2x_2 + b = 0\)，边界是一条直线。
    *   **非线性边界**：引入多项式特征（如 \(x_1^2 + x_2^2\)），决策边界就可以是圆或更复杂的曲线。

### 4. 逻辑回归的代价函数 
*   **为什么不用线性回归的均方误差？**
    *   因为将 Sigmoid 函数代入均方误差后，代价函数 \(J(\vec{w},b)\) 会变成**非凸函数 (non-convex)**，存在多个局部最小值，梯度下降容易陷入局部最优。
*   **重新定义损失函数 (Loss)**（交叉熵的核心）：
    将 \(J\) 定义为交叉熵的形式，保证函数是**凸函数 (convex)**，可以稳定地使用梯度下降找到全局最优。
    *   单个样本的损失 \(L\)：
        *   若 \(y = 1\)：\(L = -\log(f_{\vec{w},b}(\vec{x}))\) （预测越接近 \(1\) 损失越小，越接近 \(0\) 损失趋于无穷大）
        *   若 \(y = 0\)：\(L = -\log(1 - f_{\vec{w},b}(\vec{x}))\) （预测越接近 \(0\) 损失越小，越接近 \(1\) 损失趋于无穷大）
    *   **合并后的统一代价函数**：
        \[
J(\vec{w},b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(f_{\vec{w},b}(\vec{x}^{(i)})) + (1 - y^{(i)}) \log(1 - f_{\vec{w},b}(\vec{x}^{(i)})) \right]
\]

### 5. 梯度下降
*   虽然代价函数变了，但梯度下降的迭代更新公式，**在形式上与线性回归完全一致**！
    *   \(w_j = w_j - \alpha \frac{\partial}{\partial w_j} J(\vec{w}, b)\)
    *   \(b = b - \alpha \frac{\partial}{\partial b} J(\vec{w}, b)\)
*   **推导后的更新公式**：
    *   \(w_j = w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)}) x_j^{(i)}\)
    *   \(b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})\)
    *   *(注：看似和线性回归一样，但这里的 \(f_{\vec{w},b}\) 是经过 Sigmoid 处理后的输出，而不是 \(wx+b\)。)*

## 三、正则化处理

### 1. 解决过拟合的三种方法
当模型在训练集上表现极好，但在测试集上泛化能力差时（即过拟合），通常有三种解决策略：
1.  **获取更多训练数据**：数据量越大，模型越不容易死记硬背噪声。
2.  **减少特征数量**：手动或使用算法筛选掉不重要的特征。
3.  **正则化 (Regularization)**：保留所有特征，但通过惩罚参数（限制参数 \(w\) 的大小）来简化模型。

### 2. 重点分析：正则化 
正则化的核心思想是：在原本的代价函数中加上一个**惩罚项**，从而惩罚过大的参数 \(w\)。

*   **公式定义**（以线性回归为例）：
    \[
J(\vec{w},b) = \text{原始代价函数} + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
\]
    *(注：偏置项 \(b\) 通常不参与正则化，因为它不影响曲线的复杂程度)*

*   **参数 \(\lambda\) (Lambda) 的选择对拟合效果的影响**：
    *   **若 \(\lambda = 0\)**：相当于没有正则化，模型完全依赖原代价函数，容易**过拟合**。
    *   **若 \(\lambda\) 过小**：惩罚力度不够，依然无法有效解决过拟合。
    *   **若 \(\lambda\) 适中**：能在“拟合数据”和“保持参数较小”之间达到完美平衡，实现**刚好拟合 (Generalization)**。
    *   **若 \(\lambda\) 太大**：惩罚力度过猛，所有参数 \(w_j\) 都会被压得接近于 \(0\)，模型几乎只剩下偏置 \(b\)，导致**欠拟合**。



### 3. 正则化线性回归 

*   **代价函数 (Cost Function)**：
    \[
J(\vec{w},b) = \frac{1}{2m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})^2 + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
\]
*   **梯度下降更新公式 (Gradient Descent)**：
    重复以下步骤直至收敛：
\[
w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)}) x_j^{(i)} + \frac{\lambda}{m} w_j \right]
\]
\[
b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})
\]
   

### 4. 正则化逻辑回归 

*   **代价函数 (Cost Function)**：
    \[
J(\vec{w},b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(f_{\vec{w},b}(\vec{x}^{(i)})) + (1 - y^{(i)}) \log(1 - f_{\vec{w},b}(\vec{x}^{(i)})) \right] + \frac{\lambda}{2m} \sum_{j=1}^{n} w_j^2
\]
*   **梯度下降更新公式 (Gradient Descent)**：
    重复以下步骤直至收敛：
    \[
w_j = w_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)}) x_j^{(i)} + \frac{\lambda}{m} w_j \right]
\]
    \[
b = b - \alpha \frac{1}{m} \sum_{i=1}^{m} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})
\]
    *(注：虽然两者的梯度下降更新公式长得一模一样，但逻辑回归中的 \(f_{\vec{w},b}(\vec{x}^{(i)})\) 是经过 Sigmoid 函数处理后的概率输出，而线性回归是直接输出预测值。)*

# 3.2 深度学习
## 一、神经网络基础

> **核心直觉**：逻辑回归是“单个神经元”，而神经网络就是把许多个逻辑回归单元（神经元）组合在一起，形成多层结构。它可以自动提取复杂的特征，解决非线性分类/回归问题。

### 1. 神经网络的基本结构
*   **直观形式**：由输入层（Input Layer）、隐藏层（Hidden Layers）和输出层（Output Layer）组成。
*   **隐藏层的作用**：将上一层的输入特征进行加权求和后，通过**激活函数**（如 Sigmoid, ReLU）进行非线性变换，抽象出更高级的特征。
*   **层内计算逻辑**：每一层的每一个神经元，都在执行一次类似逻辑回归的计算。即：\(z = \vec{w} \cdot \vec{a} + b\)，然后 \(a = g(z)\)。

### 2. 前向传播与向量化
前向传播是指数据从输入层经过隐藏层，最终到达输出层产生预测值的过程。

*   **从伪代码到向量化**：
    *   如果不用框架，我们需要写 for 循环遍历每一层的每一个单元。
    *   但在实际中，为了极大地提升计算速度，我们使用**矩阵乘法**（向量化）：
        \[
\vec{z}^{[l]} = \mathbf{W}^{[l]} \vec{a}^{[l-1]} + \vec{b}^{[l]}
\]
        \[
\vec{a}^{[l]} = g^{[l]}(\vec{z}^{[l]})
\]
    *(注：上标 \([l]\) 表示第 \(l\) 层，\(\mathbf{W}^{[l]}\) 是该层的权重矩阵，\(\vec{a}^{[l-1]}\) 是上一层的激活值输出。)*
*   **框架实现（以 TensorFlow/Keras 为例）**：
    *   你不需要手写矩阵乘法，框架已经封装好了 `Dense` 层。
    *   `Dense(units=3, activation='sigmoid')` 的意思是：该层有 3 个神经元，使用 Sigmoid 激活函数，它会自动帮你完成矩阵运算和激活操作。

### 3. 神经网络的通用框架(TensorFlow)

```python
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

# 1. 定义模型结构 (Sequential 按顺序堆叠层)
model = Sequential([
    Dense(units=25, activation='relu'),    # 第1个隐藏层，25个单元
    Dense(units=15, activation='relu'),    # 第2个隐藏层，15个单元
    Dense(units=1, activation='sigmoid')   # 输出层，1个单元 (二分类)
])

# 2. 编译模型 (定义损失函数和优化器)
model.compile(loss=tf.keras.losses.BinaryCrossentropy())

# 3. 训练模型 (执行梯度下降和前向/反向传播)
model.fit(X, y, epochs=100)
```
### 4. 激活函数的选择 

*   **隐藏层的选择**：
    *   **ReLU** (\(g(z) = \max(0, z)\))：**最常用**。计算快，且在 \(z>0\) 时梯度不衰减（解决了 Sigmoid 在深层网络中导致的梯度消失问题）。
    *   **Sigmoid**：现在极少用于隐藏层，因为两端平缓（梯度趋近于 0），会导致梯度下降缓慢。
    *   *注：隐藏层通常不用线性激活函数（即 \(g(z)=z\)），因为多个线性层的叠加本质上依然是线性变换，失去了神经网络解决非线性问题的意义。*
*   **输出层的选择**：
    *   **二分类问题**（\(y=0\) 或 \(1\)）：**Sigmoid**。
    *   **回归问题**（预测任意实数 \(y \in (-\infty, +\infty)\)）：**线性激活函数 (Linear)**。
    *   **回归问题**（预测非负数 \(y \ge 0\)，如房价）：**ReLU**。

### 5. 训练神经网络的标准步骤

无论分类还是回归，使用框架训练模型都可以归纳为这三步：

1.  **指定模型结构并计算输出**：`model = Sequential([...])`，底层会自动执行前向传播计算 \(f_{\vec{w},b}(\vec{x})\)。
2.  **定义损失函数 (Loss Function)**：
    *   分类任务 (二元交叉熵)：`loss = BinaryCrossentropy()`
    *   回归任务 (均方误差)：`loss = MeanSquaredError()`
3.  **执行梯度下降最小化损失**：
    *   框架中只需调用 `model.fit(X, y, epochs=...)`，底层会自动使用**反向传播算法 (Backpropagation)** 计算偏导数，并更新所有权重和偏置。

### 6. 多分类 
*   **场景**：如识别猫、狗、鸟，类别互斥。
*   **激活函数 (Softmax)**：将输出转化为概率分布，所有类别的概率之和为 \(1\)。假设有 \(N\) 个类别：
    \[
a_i = \frac{e^{z_i}}{\sum_{j=1}^{N} e^{z_j}} \quad \text{其中 } z_i = \vec{w}_i \cdot \vec{x} + b_i
\]
    *   性质：\(0 \le a_i \le 1\) 且 \(\sum_{i=1}^{N} a_i = 1\) 。
*   **损失函数 (Categorical Crossentropy)**：
    \[
Loss(a_1,...,a_N,y) = - \log(a_i)  \text{ 当且仅当} y=i
\]
    *(代码对应：`SparseCategoricalCrossentropy`)*    

### 7. 多标签分类 
*   **场景**：一张图里同时有车、人、狗，标签不互斥。
*   **激活函数 (Sigmoid)**：对每个类别独立进行二分类概率计算：
    \[
a_i = g(z_i) = \frac{1}{1 + e^{-z_i}}
\]
    *   性质：各个 \(a_i\) 相互独立，总和不一定为 \(1\)。
*   **损失函数 (Binary Crossentropy)**：
    \[
Loss = - \sum_{i=1}^{N} \left[ y_i \log(a_i) + (1-y_i)\log(1-a_i) \right]
\]

## 二、算法优化与模型调优

### 1. 数据集划分与误差评估公式
为了严谨地诊断模型，我们需要在**训练集 (Train)** 和 **交叉验证集 (CV)** 上分别计算误差。

*   **带正则化的训练集误差 \(J_{train}\)**（以回归问题为例，*注意包含正则化惩罚项*）：
    \[
J_{train}(\vec{w}, b) = \frac{1}{2m_{train}} \sum_{i=1}^{m_{train}} (f_{\vec{w},b}(\vec{x}^{(i)}) - y^{(i)})^2 + \frac{\lambda}{2m_{train}} \sum_{j=1}^{n} w_j^2
\]

*   **交叉验证误差 \(J_{cv}\)**（*注意：仅计算预测误差，不包含正则化项*）：
    \[
J_{cv}(\vec{w}, b) = \frac{1}{2m_{cv}} \sum_{i=1}^{m_{cv}} (f_{\vec{w},b}(\vec{x}_{cv}^{(i)}) - y_{cv}^{(i)})^2
\]


### 2. 诊断模型
通过对比 \(J_{train}\) 和 \(J_{cv}\) 的大小，可以用数学不等式来严谨界定模型状态：

| 状态 | 数学判定条件 | 物理意义 | 解决办法 |
| :--- | :--- | :--- | :--- |
| **高偏差** (欠拟合) | \(J_{train}\) **高** 且 \(J_{cv} \approx J_{train}\) | 模型太简单，连训练集规律都没学到。 | 增加特征、增加多项式、**减小** \(\lambda\) |
| **高方差** (过拟合) | \(J_{train}\) **低** 且 \(J_{cv} \gg J_{train}\) | 模型死记硬背，泛化能力极差。 | 获取更多数据、减少特征、**增大** \(\lambda\) |

*   **\(\lambda\) (正则化参数) 的数学调节**：
    *   若 \(\lambda \to \infty\)：\(w_j \to 0\)，模型退化为常数 \(b\)，导致**高偏差**。
    *   若 \(\lambda \to 0\)：正则化失效，容易导致**高方差**。


### 3. Adam 优化算法 
传统的梯度下降 \(\alpha\) 是固定的；Adam 算法能根据参数的更新情况自动调整学习率。以下是基于 TensorFlow/Keras 的代码实现步骤：

```python
import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

# 1. 定义模型结构 (隐藏层灵活设计)
model = Sequential([
    tf.keras.layers.Dense(units=25, activation='sigmoid'),
    tf.keras.layers.Dense(units=15, activation='sigmoid'),
    tf.keras.layers.Dense(units=10, activation='linear') # 视具体任务而定
])

# 2. 编译模型 (使用 Adam 优化器)
# learning_rate=1e-3 
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True)
)
# 3. 训练模型
model.fit(X, y, epochs=100)    
```

### 4. 隐藏层结构设计

- **全连接层 (Dense)**：实现 \(Z^{[l]} = W^{[l]}A^{[l-1]} + b^{[l]}，A^{[l]} = g(Z^{[l]})\)。
* **卷积层 (Convolution)**：针对图像处理任务，隐藏层可以采用卷积层形式，利用局部感受野和权值共享提取空间特征。


### 5. Debugging学习算法

根据前面的公式判定，采取对应的工程手段：

* **如果是 High Bias (\(J_{train}\) 高)**：
  - 尝试获取更多的特征 (Try getting additional features)。
  - 尝试添加多项式特征 (Try adding polynomial features)。
  - 减小正则化参数 \lambda (Decrease \lambda)。
  - 增大神经网络规模（添加层数或神经元数量）。
* **如果是 High Variance \(J_{cv}\) 远大于 \(J_{train}\)**：
  - 获取更多训练数据 (Get more training examples)，这是解决高方差最有效的方法。
  - 尝试减少特征集合 (Try smaller set of features)。
  - 增大正则化参数 \lambda (Increase \lambda)。

### 6.数据增强与迁移学习

当模型出现特定类型的错误（例如识别不出发侧面的猫），而整体数据量又不够时，我们通常采用以下方法：
**①数据增强 (Data Augmentation)**
*   **概念**：人工制造更多训练数据，让模型学会“举一反三”，提升泛化能力。
*   **常用手段**：
    *   **图像**：镜像翻转、随机裁剪、旋转不同角度、扭曲变形。
    *   **音频**：加入背景噪声、改变音调、混合不同声音。
*   **价值**：成本极低，是在不获取新数据的情况下，解决过拟合和特定错误的最有效方式。

**②迁移学习 (Transfer Learning)**
*   **适用场景**：你的任务数据量不大，但想借用大模型的能力。
*   **核心步骤 (Step)**：
    1.  **下载预训练模型**：下载一个已经在大型数据集（如 ImageNet）上训练好的神经网络。**注意**：预训练模型的**输入类型**（如图像、音频、文本）必须与你的应用相同。
    2.  **微调 (Fine-tuning)**：替换掉输出层（针对你的类别数），然后在你自己的小数据集上进行训练，更新网络中的参数。

**机器学习完整项目周期**

*   **流程**：确定项目范围 \(\rightarrow\) 收集数据 \(\rightarrow\) 训练模型 \(\rightarrow\) **部署到生产环境**。
*   **部署考量**：推理服务器效率、系统扩展性（应对大量用户同时访问）、日志记录（系统监控）以及模型的定期更新。


### 7.模型的评估指标
在分类任务中，仅仅看“准确率 (Accuracy)”是不够的（特别是在正负样本极度不平衡时）。我们需要更精细的指标。

**①混淆矩阵 (Confusion Matrix)**
这是所有评估指标的基础。假设正类为 1，负类为 0：

| 实际情况 \ 预测情况 | 预测为 1 (Positive) | 预测为 0 (Negative) |
| :--- | :--- | :--- |
| **实际为 1 (Positive)** | **TP** (True Positive) <br>真正例 | **FN** (False Negative) <br>假负例 (漏报) |
| **实际为 0 (Negative)** | **FP** (False Positive) <br>假正例 (误报) | **TN** (True Negative) <br>真负例 |

**②精确率 (Precision) 与 召回率 (Recall)**
*   **精确率 (Precision)**：在所有**预测为正**的样本中，真正为正的比例。
    *   *含义*：模型说是对的，有多大概率是真的对？（**尽量少误报**）
    *   **公式**：\[
P = \frac{TP}{TP + FP}
\]
*   **召回率 (Recall)**：在所有**实际为正**的样本中，被模型成功预测出来的比例。
    *   *含义*：真正有病的人，模型能查出来多少？（**尽量少漏报**）
    *   **公式**：\[
R = \frac{TP}{TP + FN}
\]

**③权衡 (Trade-off) 与 F1 Score**
*   **阈值 (Threshold)**：通过调整预测为正类的概率阈值（默认 0.5），可以打破精确率和召回率的平衡。
    *   **提高阈值**（如 0.7）：预测变得更严格 \(\rightarrow\) 精确率上升，召回率下降。
    *   **降低阈值**（如 0.3）：预测变得更宽松 \(\rightarrow\) 召回率上升，精确率下降。
*   **F1 Score**：精确率和召回率的**调和平均数**。当我们需要同时兼顾两者时，使用这个综合指标。
    *   **公式**：\[
F_1 = \frac{2}{\frac{1}{P} + \frac{1}{R}} = 2 \frac{P \cdot R}{P + R}
\]

> **注意**：
> 理解精确率和召回率的核心在于**业务场景**：
> *   如果是**癌症筛查**，人命关天，我们宁可误报（FP），也要尽量不漏报（FN），此时追求**高召回率**。
> *   如果是**垃圾邮件过滤**，我们宁可漏掉几封垃圾邮件，也不能把老板的重要邮件当成垃圾邮件拦截了，此时追求**高精确率**。

## 三、决策树与树集成模型

> **核心直觉**：决策树就像是在玩“猜猜看”游戏，通过不断提问（特征判断）来一步步缩小范围，直到得出结论。单棵决策树容易死记硬背（高方差），因此常常使用**集成学习**（随机森林、XGBoost）将多棵树组合起来，以提升泛化能力。

### 1. 决策树基础模型 

*   **基本结构**：
    *   **根节点 (Root Node)**：包含所有样本的起点（Depth 0）。
    *   **决策节点 (Decision Node)**：根据某个特征进行判断的分支点。
    *   **叶节点 (Leaf Node)**：最终的预测结果（类别或连续值）。
*   **构建时的两个核心决策**：
    1.  **如何选择特征进行分裂？** \(\rightarrow\) 选择让**纯度提升最大**的特征。
    2.  **何时停止分裂？**（防止过拟合） \(\rightarrow\) 达到最大深度、纯度提升低于阈值、或节点样本数低于阈值。

### 2. 熵与信息增益 
**①测量纯度（熵）**
为了衡量数据的“纯度”，我们引入**熵 (Entropy)**。对于只有正负两类（比例分别为 \(p_1\) 和 \(p_2\)，且 \(p_1 + p_2 = 1\)）的样本：
\[
H(p_1) = -p_1 \log_2(p_1) - p_2 \log_2(p_2)
\]
* 特征：当 \(p_1 = 0.5\) 时（最混乱），熵最大为 1；当 \(p_1 = 0\) 或 1 时（最纯），熵为 0。

**②信息增益公式与符号详解**
信息增益 (Information Gain, IG) 表示：**用某个特征分裂数据后，整个系统“不确定性（熵）”减少的程度**。决策树每次都会挑选信息增益最大的特征进行分裂。

\[
IG = H(p_{root}) - \left( w_{left} \cdot H(p_{left}) + w_{right} \cdot H(p_{right}) \right)
\]

*   **\(H(p_{root})\)**：**分裂前**根节点的熵。\(p\) 代表正样本的比例，\(H(p) = -p \log_2(p) - (1-p)\log_2(1-p)\)。
*   **\(w_{left}\) 和 \(w_{right}\)**：左右子节点的**样本权重**（等于左/右节点样本数除以总样本数）。
*   **\(H(p_{left})\) 和 \(H(p_{right})\)**：**分裂后**左右子节点的熵。
*   **括号内的部分**：计算的是分裂后系统总熵的加权平均值。用分裂前的熵减去它，就是这次分裂带来的“纯度提升”。

### 3. 回归树

当决策树用于预测连续数值（如预测房价、年龄）时，评估纯度的标准不再是熵，而是**方差 (Variance)**。我们希望同一个叶子节点内的样本，其目标值 \(y\) 越接近越好。

**计算公式**
*   **节点的方差**：假设该节点有 \(m\) 个样本，目标值均值为 \(\bar{y}\)：
    \[
V = \frac{1}{m} \sum_{i=1}^{m} (y_i - \bar{y})^2
\]
*   **方差缩减 (Variance Reduction)**：决策树寻找最佳的连续特征切分点，使得分裂后的加权方差最小，即**方差缩减最大**：
    \[
\text{方差缩减} = V_{root} - \left( \frac{m_{left}}{m_{total}} V_{left} + \frac{m_{right}}{m_{total}} V_{right} \right)
\]

**具体计算例子**
假设当前节点有 4 个样本，真实房价 \(y = [10, 20, 30, 40]\)（单位：万）。
1.  **计算根节点方差**：
    *   均值 \(\bar{y} = 25\)。
    *   \(V_{root} = \frac{1}{4}[(10-25)^2 + (20-25)^2 + (30-25)^2 + (40-25)^2] = \frac{1}{4}[225+25+25+225] = 125\)。
2.  **尝试按照特征 \(x \le 15\) 进行分裂**：
    *   左节点（2个样本）：\(y = [10, 20]\)。均值 15。\(V_{left} = \frac{1}{2}[(10-15)^2 + (20-15)^2] = 25\)。权重 \(w_{left} = 2/4 = 0.5\)。
    *   右节点（2个样本）：\(y = [30, 40]\)。均值 35。\(V_{right} = \frac{1}{2}[(30-35)^2 + (40-35)^2] = 25\)。权重 \(w_{right} = 2/4 = 0.5\)。
    *   加权后方差 = \(0.5 \times 25 + 0.5 \times 25 = 25\)。
    *   **方差缩减** = \(125 - 25 = 100\)。
3.  **结论**：决策树会遍历所有可能的切分点，找出能带来最大方差缩减的阈值进行节点分裂。

### 4. 独热编码 

*   **问题**：决策树无法直接处理文本类别（如颜色：红、绿、蓝）。如果简单编码为 1、2、3，模型会误认为存在大小关系。
*   **解决方案**：将每个类别转换为独立的二进制特征（如：红变成 `[1,0,0]`，绿变成 `[0,1,0]`，蓝变成 `[0,0,1]`）。如果有 10 个类别，就会生成 10 个新特征。

### 5. 树集成 (随机森林与XGBoost)

单棵树极易过拟合，集成学习通过组合多棵树来降低方差。

**① 随机森林 - Bagging**
*   **核心思想**：**并行训练，集体投票**。通过构建很多棵独立的树，最后综合它们的结果，以此来**降低方差（减少过拟合）**。
*   **两大随机性（关键点）**：
    1.  **数据随机（有放回抽样 Bootstrap）**：从 \(m\) 个样本中，有放回地随机抽取 \(m\) 个样本，生成不同的训练集（通常会有约 36.8% 的样本抽不到）。重复这个过程，构建出**约 100 棵**左右的决策树。
    2.  **特征随机**：在树的每个节点进行分裂时，不是从所有特征中找最优，而是**随机挑选出总特征数量的平方根（\(\sqrt{n}\)）个特征**，从中选最优。这保证了树与树之间的差异性。
*   **预测方式**：分类任务用多数投票（少数服从多数），回归任务取所有树的平均值。
*   **代码实现**：
```python
from sklearn.ensembleimportRandomForestClassifie,RandomForestRegressor

# 分类任（n_estimators 就是的棵树，通常设为100）
rf_clf =RandomForestClassifie(n_estimators=100,random_state=42)
rf_clf.fit(X_train,y_train)
y_pred = rf_clfpredict(X_test)

# 回归任务
rf_reg =RandomForestRegresso(n_estimators=100,random_state=42)
rf_reg.fit(X_train,y_train)
```

**② XGBoost - Boosting**
*   **核心思想**：**串行训练，纠错接力**。后一棵树专门去学习前一棵树的残差（错误），以此来**降低偏差（提升拟合能力）**。
*   **工作机制**：第一棵树预测后产生误差；第二棵树以这个误差为目标进行训练；第三棵树再去拟合第二棵树的误差…… 叠加所有树的预测结果。
*   **代码实现:**

```python
# 分类任务
from xgboost import XGBClassifier
model = XGBClassifier()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 回归任务
from xgboost import XGBRegressor
model = XGBRegressor()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

| **数据预处理** | 需手动处理独热编码等 | 能自动提取特征 |

# 3.3 无监督学习

## 一、聚类

> **核心直觉**：无监督学习没有标签 \(y\)。聚类算法的目的就是将相似的数据点自动分到一组（簇 Cluster）。K-means 是最常用的聚类算法。

### 1. K-means 的核心思想
K-means 算法通过不断迭代以下两个步骤，直到聚类中心不再移动：
1.  **分配 (Assign)**：查看每个数据点，将其分配给距离最近的聚类中心。
2.  **更新 (Move)**：将新的聚类中心移动到其包含的所有数据点的均值（中心）位置。

### 2. 算法流程 (伪代码)

1.  **随机初始化** \(K\) 个聚类中心：\(\mu_1, \mu_2, ..., \mu_K\)。
2.  **Repeat** {
    *   **分配点**：
        `for i = 1 to m`（\(m\) 为样本数）
        \(c^{(i)} := \text{index (from 1 to K) of cluster centroid closest to } x^{(i)}\)
        *(将第 \(i\) 个样本分配给距离最近的中心)*
    *   **移动中心**：
        `for k = 1 to K`
        \(\mu_k := \text{average (mean) of points assigned to cluster } k\)
        *(将第 \(k\) 个中心移动到其包含样本的均值处)*
3.   直到聚类中心位置不再发生改变。

*   **特殊情况处理**：如果出现了某个聚类中心没有分配到任何点，通常的做法是**消除该聚类**（直接减少 \(K\) 值）或者**重新随机初始化**该中心。

### 3. 目标函数 
K-means 也有一个需要最小化的代价函数，有时被称为**失真函数 (Distortion Function)**。

*   **符号定义**：
    *   \(c^{(i)}\)：第 \(i\) 个样本被划分到的类编号（取值 \(1, 2, ..., K\)）。
    *   \(\mu_k\)：第 \(k\) 个类的聚类中心（质心），是一个向量。
    *   \(\mu_{c^{(i)}}\)：第 \(i\) 个样本**所属类**的聚类中心。
*   **代价函数公式**：
    \[
J(c^{(1)}, ..., c^{(m)}, \mu_1, ..., \mu_K) = \frac{1}{m} \sum_{i=1}^{m} ||x^{(i)} - \mu_{c^{(i)}}||^2
\]
    *(即：所有样本点到其所属聚类中心距离平方的平均值)*
*   **优化目标**：
    \[
\min_{c^{(1)}, ..., c^{(m)}, \mu_1, ..., \mu_K} J
\]
    算法的“分配”步骤就是固定中心找最优 \(c\)；“移动”步骤就是固定 \(c\) 找最优 \(\mu\)。两个步骤交替进行，必定会让代价函数 \(J\) 不断下降并收敛。

### 4. 初始化策略
K-means 容易陷入局部最优，因此需要多次随机初始化。

*   **步骤**：
    1.  选择 \(K < m\)（\(K\) 为聚类数，\(m\) 为样本数）。
    2.  随机选取 \(K\) 个训练样本作为初始聚类中心 \(\mu_1, ..., \mu_K\)。
    3.  循环运行 50 到 1000 次：
        *   随机初始化 K-means。
        *   运行算法得到 \(c, \mu\)。
        *   计算代价函数 \(J\)。
    4.  **选择给出最低代价 \(J\) 的那组聚类结果**。

### 5. 聚类数量 \(K\)的选择
\(K\) 的选择往往没有标准答案，取决于你的业务需求。

*   **方法一：肘部法则 (Elbow Method) —— 不太好用**
    *   画出代价函数 \(J\) 随 \(K\) 值变化的曲线。
    *   如果曲线在某一个点出现明显的“拐点”（比如 \(K=3\) 时下降明显，之后变得平缓），这个拐点就像是人的胳膊肘，这个 \(K\) 值可能是不错的选择。
    *   **局限性**：很多时候曲线是平滑下降的，找不到明显的“肘部”，此时该方法失效。
*   **方法二：根据下游任务的表现来评估 (最推荐)**
    *   K-means 通常是为了后续任务服务的。例如做服装尺码聚类（S, M, L），到底是分 3 类（S/M/L）还是 5 类（XS/S/M/L/XL），完全取决于你的商业目标和市场需求。
    *   通过评估不同 \(K\) 值对**最终业务指标**（如销量、客户满意度）的影响来决定 \(K\)。

## 二、异常检测 
> **核心直觉**：通过大量“正常”的样本数据，学习出一个概率模型 \(p(x)\)（即样本出现的概率密度）。当出现一个新样本时，如果它发生的概率极高，则为正常；如果发生的概率极低（低于某个阈值 \(\epsilon\)），则判定为异常。

### 1. 密度估计与高斯分布 

**核心假设**
假设每个特征 \(x_j\) 都服从**正态分布（高斯分布）**，且各个特征之间相互独立。
*   **单特征概率**：
    \[
P(x_j; \mu_j, \sigma_j^2) = \frac{1}{\sqrt{2\pi}\sigma_j} \exp\left(-\frac{(x_j - \mu_j)^2}{2\sigma_j^2}\right)
\]
*   **多维特征联合概率**（由于假设独立，等于各自概率的乘积）：
    \[
p(x) = \prod_{j=1}^{n} P(x_j; \mu_j, \sigma_j^2)
\]

**参数估计** 
利用训练集（通常是大量无标签的正常数据）计算每个特征的均值 \(\mu_j\) 和方差 \(\sigma_j^2\)：
\[
\mu_j = \frac{1}{m} \sum_{i=1}^{m} x_j^{(i)}
\]
\[
\sigma_j^2 = \frac{1}{m} \sum_{i=1}^{m} (x_j^{(i)} - \mu_j)^2
\]

### 2. 异常检测算法流程 

1.  **选择特征**：选择你认为可能指示异常的 \(n\) 个特征 \(x_1, ..., x_n\)。
2.  **拟合参数**：在训练集上计算每个特征的 \(\mu_1...\mu_n\) 和 \(\sigma_1^2...\sigma_n^2\)。
3.  **计算新样本的概率**：给定一个新样本 \(x\)，计算 \(p(x) = \prod_{j=1}^{n} P(x_j; \mu_j, \sigma_j^2)\)。
4.  **做出判断**：
    *   若 \(p(x) < \epsilon\)，判定为**异常 (Anomaly)**。
    *   若 \(p(x) \ge \epsilon\)，判定为**正常 (Normal)**。

### 3. 模型评估与参数选择 

虽然异常检测属于无监督学习，但在**开发阶段**，我们需要利用少量的**带标签数据**（已知的异常样本）来评估模型。

*   **数据集划分**：
    *   **训练集**：大量正常数据（\(y=0\)）。
    *   **交叉验证集 (CV)** 和 **测试集**：包含正常数据和少量异常数据（\(y=1\)）。
*   **评估方法**：在 CV / Test 集上跑算法，因为样本极度不平衡（正常多，异常极少），不能用准确率 (Accuracy)，必须使用：
    *   **True Positive, False Positive, False Negative, True Negative**
    *   **Precision (精确率)** / **Recall (召回率)**
    *   **F1-score**
*   **阈值 \(\epsilon\) 的选择**：利用**交叉验证集**，尝试不同的 \(\epsilon\) 值，选择能让 F1-score 最大的那个 \(\epsilon\)。

### 4. 异常检测 vs 监督学习 

既然有标签，为什么不用监督学习（如逻辑回归）？关键区别在于**样本分布**和**业务场景**。

| 特性 | 异常检测 (Anomaly Detection) | 监督学习 (Supervised Learning) |
| :--- | :--- | :--- |
| **正类样本 (y=1)** | **极少**（如只有 0~20 个正样本） | **很多**（通常有大量正样本） |
| **负类样本 (y=0)** | **极多**（海量正常数据） | 很多 |
| **模型假设** | 只学习“正常”的长相，凡是跟正常不一样的都叫异常。 | 学习“正常”和“异常”各自的特征。假设未来的正样本与训练集中的相似。 |
| **适用场景** | 1. 欺诈检测（如信用卡盗刷，与过往交易模式不同）<br>2. 工业制造缺陷检测<br>3. 数据中心服务器异常监控 | 1. 垃圾邮件过滤（有大量相似特征的垃圾邮件）<br>2. 天气预报<br>3. 图像分类 |

*   *总结：如果异常的种类千奇百怪，无法用固定的模式概括（只要与正常不同就标为异常），且异常样本极少，选异常检测。*

### 5. 特征工程与调优 

*   **确保特征符合高斯分布**：如果特征分布极度偏斜（如长尾分布），可以先进行数学变换使其近似正态分布，例如：
    *   取对数：\(x \leftarrow \log(x + c)\)
    *   取平方根：\(x \leftarrow \sqrt{x}\)
*   **误差分析（找新特征）**：
    1.  训练模型。
    2.  查看算法在交叉验证集中**未能检测出**的异常样本。
    3.  观察这些样本，寻找突破口（例如 CPU 负载很高，但网络流量很低）。
    4.  **创建新特征**（例如：CPU 负载 / 网络流量），使得这些异常样本在新特征上的取值异常大/小，从而成功识别它们。

## 三、推荐系统与协同过滤

> **核心直觉**：推荐系统的本质是“填补矩阵中的缺失值”。基于内容的推荐需要已知特征；而**协同过滤 (Collaborative Filtering)** 则是在既没有用户偏好特征、也没有物品特征的情况下，通过用户和物品的相互评价数据，同时学习出用户的偏好和物品的特征。

### 1. 问题定义与数据结构
以电影评分为例（\(n_u\) 个用户，\(n_m\) 部电影）：
*   **\(y^{(i,j)}\)**：用户 \(j\) 对电影 \(i\) 的评分（若没看过，则无数据，用 `?` 表示）。
*   **\(r(i,j)\)**：指示变量，若用户 \(j\) 评价过电影 \(i\) 则为 1，否则为 0。
*   **\(x^{(i)}\)**：电影 \(i\) 的特征向量（如浪漫指数、动作指数）。
*   **\(w^{(j)}, b^{(j)}\)**：用户 \(j\) 的模型参数。

预测用户 \(j\) 对电影 \(i\) 的评分公式为：\((w^{(j)})^T x^{(i)} + b^{(j)}\)。

### 2. 基于电影特征的预测
**已知 \(X\)，求 \(w, b\)**
假设每部电影都已经有了特征向量 \(x^{(i)}\)。对于每个用户 \(j\)，这本质上是一个**线性回归**问题：
*   **单个用户的代价函数**：
    \[
J(w^{(j)}, b^{(j)}) = \frac{1}{2} \sum_{i:r(i,j)=1} \left( (w^{(j)})^T x^{(i)} + b^{(j)} - y^{(i,j)} \right)^2 + \frac{\lambda}{2} \sum_{k=1}^{n} (w_k^{(j)})^2
\]
*   **所有用户的代价函数**（求和）：
    \[
J(w, b) = \sum_{j=1}^{n_u} J(w^{(j)}, b^{(j)})
\]
*   利用梯度下降可以求出所有用户的参数。

### 3. 基于用户参数的预测
**已知 \(w, b\)，求 \(X\)**
反过来，如果我们问卷调查得到了所有用户的偏好参数 \(w, b\)，想推测某部电影的特征 \(x^{(i)}\)（这相当于在一个反向的线性回归问题）。
*   **单部电影的代价函数**：
    \[
J(x^{(i)}) = \frac{1}{2} \sum_{j:r(i,j)=1} \left( (w^{(j)})^T x^{(i)} + b^{(j)} - y^{(i,j)} \right)^2 + \frac{\lambda}{2} \sum_{k=1}^{n} (x_k^{(i)})^2
\]
*   **所有电影的代价函数**：
    \[
J(x) = \sum_{i=1}^{n_m} J(x^{(i)})
\]

### 4. 协同过滤算法 
现实中我们往往既没有 \(X\)，也没有 \(w, b\)。协同过滤的伟大之处在于：**将上面两个代价函数合并，同时优化 \(w, b\) 和 \(X\)。**

*   **联合代价函数**：
    \[
J(w, b, x) = \frac{1}{2} \sum_{(i,j):r(i,j)=1} \left( (w^{(j)})^T x^{(i)} + b^{(j)} - y^{(i,j)} \right)^2 + \frac{\lambda}{2} \sum_{j=1}^{n_u} \sum_{k=1}^{n} (w_k^{(j)})^2 + \frac{\lambda}{2} \sum_{i=1}^{n_m} \sum_{k=1}^{n} (x_k^{(i)})^2
\]
    *(注：协同过滤中通常不使用 \(x_0=1\) 这个截距项，而是用 \(b\) 来处理偏置，所以 \(x\) 的维度是 \(n\) 而不是 \(n+1\))*。
*   **梯度下降更新**：
    *   \(w_k^{(j)} = w_k^{(j)} - \alpha \frac{\partial}{\partial w_k^{(j)}} J\)
    *   \(b^{(j)} = b^{(j)} - \alpha \frac{\partial}{\partial b^{(j)}} J\)
    *   \(x_k^{(i)} = x_k^{(i)} - \alpha \frac{\partial}{\partial x_k^{(i)}} J\)

### 5. 均值归一化 
**问题**：如果一个新用户（如 Eve）没有给任何电影打分（\(r(i,j)=0\)），模型会计算出她的 \(w=0, b=0\)。那么预测她对所有电影的评分都是 \(0\) 星，这显然不合理。
**解决**：先计算每部电影的平均评分 \(\mu_i\)，将评分矩阵减去均值（得到均值为 \(0\) 的矩阵）再进行训练。
**预测时**：加上均值 \(\mu_i\)。
\[
\text{Prediction}_{(i,j)} = (w^{(j)})^T x^{(i)} + b^{(j)} + \mu_i
\]
这样，即使新用户参数全为 \(0\)，预测结果也会是 \(\mu_i\)（即平均分），更符合常理。



### 6. 二元标签情形 
“二元标签 (用户只输入 1/0/?)”，是推荐系统中的**隐式反馈**场景。

*   **常规场景**：用户给电影打 1-5 星，这是连续值，用线性回归（均方误差）。
*   **二元标签场景**：用户并没有打分，只是**看了 / 没看**，**买了 / 没买**（如短视频点赞、商品点击）。此时 \(y^{(i,j)}\) 只有 \(1\)（参与）、\(0\)（未参与）和 \(?\)（未知）。
*   **怎么处理？**
    此时预测的不再是评分，而是**用户参与的“概率”**。因此，模型变为**逻辑回归**：
    1. 预测函数引入 Sigmoid：\(f_{(w,b,x)}(i,j) = g((w^{(j)})^T x^{(i)} + b^{(j)})\)，输出 \(0 \sim 1\) 的概率。
    2. 损失函数（代价函数）替换为**二元交叉熵 (Binary Crossentropy)**：
       \[
L = -y \log(f) - (1-y)\log(1-f)
\]
    3. 同样使用梯度下降同时更新用户参数和电影特征。


### 7. 协同过滤的TensorFlow 
由于协同过滤需要同时优化两组参数（\(w,b\) 和 \(x\)），手动求导极易出错。利用 TensorFlow 的 `tf.GradientTape` 可以自动计算梯度。

```python
import tensorflow as tf
import numpy as np

# 假设已知的评分数据
# Y 是评分矩阵，R 是指示矩阵 (1 表示有评分，0 表示无)
# nm (电影数), nu (用户数), n (特征维度)

# 1. 初始化参数为 tf.Variable (可训练变量)
W = tf.Variable(tf.random.normal([nu, n]))
b = tf.Variable(tf.zeros([nu])) # 可以不用b，合并到W中
X = tf.Variable(tf.random.normal([nm, n]))

optimizer = tf.keras.optimizers.Adam(learning_rate=1e-3)

# 2. 定义代价函数
def cofi_cost_func_v(X, W, b, Y, R, lambda_):
    # 计算所有预测值 (nm, nu)
    y_pred = tf.matmul(X, tf.transpose(W)) + b 
    # 只计算 R=1 的误差，并加入正则化项
    error = (y_pred - Y) * R 
    cost = tf.reduce_sum(error**2) / 2 
    cost += (lambda_ / 2) * (tf.reduce_sum(X**2) + tf.reduce_sum(W**2))
    return cost

# 3. 训练循环 (Gradient Tape 自动求导)
iterations = 200
for iter in range(iterations):
    with tf.GradientTape() as tape:
        cost_value = cofi_cost_func_v(X, W, b, Y, R, lambda_=1.0)
    
    # 获取 X, W, b 的梯度
    grads = tape.gradient(cost_value, [X, W, b])
    # 应用梯度更新参数
    optimizer.apply_gradients(zip(grads, [X, W, b]))
    
    if iter % 20 == 0:
        print(f"Iteration {iter}: Cost {cost_value.numpy()}")
```

## 四、基于内容的过滤 

> **核心动机**：传统的协同过滤存在**冷启动问题**。当一个新用户注册（没有任何评分记录），或者上架了一部新电影（没有任何人看过）时，协同过滤无法预测。
> **解决方案**：引入用户特征（如年龄、性别、国家）和物品特征（如年份、类型、评分），通过学习一个映射关系，将特征分别转化为用户向量 \(V_u\) 和物品向量 \(V_m\)，从而计算两者的匹配度。

### 1. 协同过滤的局限性
协同过滤完全依赖用户和物品的**交互历史**（如打分矩阵）。
*   **新用户**：没有打分记录，无法利用他人的相似性为其推荐。
*   **新物品**：没有被打分记录，无法计算与其他物品的相似度。
*   基于内容的过滤则**只需要用户和物品的静态特征**（通过问卷调查或物品属性获取），就可以进行预测。

### 2. 核心思想与预测公式

引入特征后，我们将问题转化为：根据用户特征 \(x_u\) 和物品特征 \(x_m\)，预测评分。

**①向量生成**
*   \(V_u\)：根据用户特征 \(x_u\)（如年龄、性别、国家），通过神经网络（或线性层）提取出的**用户向量**。
*   \(V_m\)：根据物品特征 \(x_m\)（如年份、类型），通过神经网络提取出的**物品向量**。
*   **关键点**：\(V_u\) 和 \(V_m\) 的维度必须相同（例如都是 32 维的向量）。

**②预测评分**
用户 \(u\) 对物品 \(m\) 的预测评分，等于两个向量的**点积 (Dot Product)**：
\[
\text{Prediction} = V_u \cdot V_m
\]
*   **代价函数**：预测评分与真实评分 \(y^{(i,j)}\) 的平方误差（可加上正则化项），通过梯度下降训练网络。

**③归一化与余弦相似度**
为了防止某个向量长度过大导致点积失真，通常会对 \(V_u\) 和 \(V_m\) 进行 **L2 归一化**。
\[
||V||_2 = \sqrt{V_1^2 + V_2^2 + ... + V_n^2}
\]
\[
V_{norm} = \frac{V}{||V||_2}
\]
归一化之后，向量的长度均为 1。此时两个向量的点积就等于它们的**余弦相似度 (Cosine Similarity)**：
*   \(V_u \cdot V_m\) 接近 1：两个向量方向高度一致，说明用户喜欢该物品。
*   \(V_u \cdot V_m\) 接近 -1：方向相反，说明用户讨厌该物品。

### 3. 推荐系统的两阶段架构 

面对海量数据，不可能对每个用户和每个物品都算一遍点积。因此，推荐系统通常分为两步：

**Step 1：检索 (Retrieval / 召回)**
*   **目标**：从海量数据中快速筛选出一批候选物品。
*   **做法**：使用较简单的模型或规则（如计算相似度、热门推荐、分类筛选），选出几百个用户可能喜欢的物品。
*   **权衡**：数量要足够多，避免漏掉用户喜欢的（上限高），但计算量不能太大。

**Step 2：排序 (Ranking / 精排)**
*   **目标**：对召回的物品进行精准打分排序。
*   **做法**：使用复杂的神经网络模型（如前面提到的 \(V_u \cdot V_m\)），对这上百个候选物品计算精确的预测评分，按分数从高到低展示给用户。
*   **优化**：通过离线 A/B 测试，增加召回物品的数量，观察用户点击率、留存率等指标是否上升。

### 4. 基于内容过滤的TensorFlow
基于内容的过滤在代码中通常实现为**双塔模型 (Two-tower Model)**：一个塔处理用户特征，另一个塔处理物品特征，最后在顶层计算点积。

```python
import tensorflow as tf

# 1. 构建用户特征提取塔 (User Tower)
user_NN = tf.keras.models.Sequential([
    tf.keras.layers.Dense(256, activation='relu'),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(32) # 输出维度为32的向量 Vu
])

# 2. 构建物品特征提取塔 (Item Tower)
item_NN = tf.keras.models.Sequential([
    tf.keras.layers.Dense(256, activation='relu'),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(32) # 输出维度为32的向量 Vm
])

# 3. 定义输入并连接网络
input_user = tf.keras.layers.Input(shape=(num_user_features,))
vu = user_NN(input_user)
# 对用户向量进行 L2 归一化
vu = tf.linalg.l2_normalize(vu, axis=1) 

input_item = tf.keras.layers.Input(shape=(num_item_features,))
vm = item_NN(input_item)
# 对物品向量进行 L2 归一化
vm = tf.linalg.l2_normalize(vm, axis=1) 

# 4. 计算点积得到预测结果
output = tf.keras.layers.Dot(axes=1)([vu, vm])

# 5. 构建完整模型并编译
model = tf.keras.Model([input_user, input_item], output)
# 因为输出的是评分预测，所以使用均方误差
model.compile(loss=tf.keras.losses.MeanSquaredError(), optimizer='adam')

# 训练时传入用户的特征和物品的特征作为输入，真实评分作为标签
# model.fit([X_user, X_item], y_ratings, epochs=...)
```

## 五、主成分分析 

> **核心思想**：PCA 是一种**降维**算法。它通过寻找数据中“方差最大”的方向（即主成分），将高维数据投影到低维空间，同时尽可能保留原始数据的信息（距离/方差）。

### 1. PCA 与线性回归的本质区别 
虽然两者都是在找一条线（或平面），但优化的目标完全不同：

*   **线性回归 (Linear Regression)**：
    *   目标：最小化**垂直距离**（即真实值 \(y\) 和预测值 \(\hat{y}\) 之间的误差）。
    *   侧重于用 \(x\) 预测 \(y\)。
*   **PCA**：
    *   目标：最小化**投影距离**（即数据点到主轴的正交距离）。
    *   侧重于寻找数据本身分布最广的方向，不区分自变量和因变量。

### 2. PCA 的 sklearn 实现步骤

在使用 PCA 之前，**必须进行特征缩放（标准化）**。因为 PCA 对特征的量纲极其敏感，量纲大的特征会主导主成分的方向。

1.  **拟合 (fit)**：计算数据的均值，并找到方差最大的 \(k\) 个主成分方向（特征向量）。
2.  **查看方差贡献率**：通过 `explained_variance_ratio_` 属性，查看各个主成分保留了原始数据多少百分比的信息。
3.  **转换 (transform)**：将原始数据投影到选定的主成分轴上，得到降维后的新特征。

### 3. 代码示例

以下为笔记中提取的两种降维情况的代码实现：

```python
import numpy as np
from sklearn.decomposition import PCA

# 原始数据 (6个样本，2个特征)
X = np.array([[1, 1], [2, 1], [3, 2], [1, -1], [2, -1], [3, -2]])

# ==========================================
# 示例 1：降维到 1 维
# ==========================================
pca_1 = PCA(n_components=1) # 目标降维到 1 维
pca_1.fit(X)                # 拟合数据，找到主成分

# 查看第一主成分的方差贡献率
# 例如，第一主成分保留了 99.2% 的方差
var_ratio_1 = pca_1.explained_variance_ratio_ 
print("方差贡献率:", var_ratio_1) # 输出大致为 [0.992]

# 将原数据投影到 1 维空间
X_trans_1 = pca_1.transform(X) 

# 还原数据 (从1维投影空间重构回2维原始空间)
X_reduced_1 = pca_1.inverse_transform(X_trans_1)


# ==========================================
# 示例 2：降维到 2 维 (保留所有成分，常用于可视化)
# ==========================================

pca_2 = PCA(n_components=2)
pca_2.fit(X)

# 查看各主成分贡献率
# 2: 0.008 (即第二个成分只占 0.8%)
var_ratio_2 = pca_2.explained_variance_ratio_ 
print("方差贡献率:", var_ratio_2) # 输出大致为 [0.992, 0.008]

# 投影转换
X_trans_2 = pca_2.transform(X)
X_reduced_2 = pca_2.inverse_transform(X_trans_2)
```
